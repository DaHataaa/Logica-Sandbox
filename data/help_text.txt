BLOCK PLACING
 1-0          - Block choosing
 WASD         - Block direction
 LMC          - Place chosen block
 R            - Delete block

NAVIGATION
 RMC+drag     - Moving
 MouseWheel   - Zoom
 T            - Layer Up
 G            - Layer Down

SELECTING
 E+drag       - Select area
 C            - Copy selected area
 V            - Paste selected area
 X            - Cut selected area
 R            - Clear selected area
 D            - Deselect

KEYBOARD ONLY
 Arrows       - Mooving the cursor
 -/+ keys     - Zoom
 F            - Place chosen blook

MAP SAVING
 Ctrl+S       - Save current map if exists
 Ctrl+Shift+S - Save current map as a new one

OTHER
 F/LMC        - Edit Text block


TIPS:
 - Type "-1" or "max" in SIM. Speed field to disable the TPS limit
 - There are no tips else
